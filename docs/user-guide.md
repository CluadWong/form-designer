# 工作票表单设计器 · 普通用户操作指南

> 面向**不使用电脑编程、只要把工作票设计出来并打印**的同事。
> 本文只讲“怎么用”，不出现技术黑话；看懂就能上手。
> 本指南同时内置在工具里：界面右上方点 **「帮助」** 按钮即可随时查看（内容与本文件一致）。

---

## 1. 这个工具是做什么的

用来**设计固定版式的工作票表单**，设计好一次，以后每次作业直接填写、打印。

- 你设计的“空表样子”叫 **模板**。
- 每次作业时往表里填的具体内容（如“工作负责人：张三”）叫 **填写数据**。
- 模板设计好可以**反复使用**，每次填不同的数据、打印不同的票。

## 2. 界面五大区域

打开后屏幕分五块，记住位置就行：

| 区域 | 在哪 | 干什么 |
|------|------|--------|
| **顶部工具栏** | 最上面一条 | 新建、保存、预览、打印、导入导出 |
| **左侧栏** | 左边 | 放组件的“零件库” + 整张表的结构树 |

| **右侧属性面板** | 右边 | 选中某个东西后，在这里改它的具体设置 |
| **底部状态栏** | 最下面一条 | 显示共几页、有没有问题、打印出几张 |

## 3. 两个模式：设计 / 预览

工具栏右侧有 **「预览」** 按钮，点一下在两种状态间切换：

- **设计态**（默认）：用来搭模板、改结构、调属性。这时你可以随意增删组件、拖动位置。
- **预览态**：切换到 **「退出预览」**。这时画面接近最终打印效果，输入框可以**直接打字填写**，用来检查版式对不对、内容放不放得下。刚进入预览时输入框是**空的**（不预置任何数据），内容靠你填写，或用「导入数据 / 读取数据」载入。

> 记不住就记住一句：**设计时搭架子，预览时填内容。**

---

## 4. 两个概念：模板 与 填写数据（一定要分清）

这是最容易混的，先讲清：

- **模板** = 空的表单版式。包含哪些“网格”、哪些“输入框”、标题写什么字。它**不包含**某次作业填的具体内容。
- **填写数据** = 某一次使用时，写进各个输入框的具体值（如“单位：检修一班”“工作内容：更换绝缘子”）。

两者分开保存：

- 模板 → 用工具栏 **「模板」** 那一组的 **保存模板 / 读取模板 / 导出文件 / 导入文件**。
- 填写数据 → 用工具栏 **「填充数据」** 那一组的 **保存数据 / 读取数据 / 导入数据 / 导出数据**（**这组不限预览态**，随时都能点）。

> **导出数据 / 保存数据**不限预览态：它们扫一遍画布上的输入框，把「字段 → 值」采集出来（设计态下值就是你在属性面板里设的默认值）。表单里一个输入框都没配时，导出（保存）的就是一个空对象 `{}`。
>
> **导出文件**与**导出数据**点击后除了下载 JSON，还会把同一份 JSON 打印到浏览器控制台（F12 → Console），对接系统时可以直接从控制台复制。

## 5. 从零设计一张票（标准流程）

1. **新建空白**：点工具栏「新建空白」，得到一张空纸。
2. **搭大框**：从左侧「布局组件」拖一个 **「网格」** 到画布。网格就是一块布局区，里面按行列分成若干 **格子**。
3. **放内容**：从左侧「基础组件」把 **文本 / 输入框 / 图片 / HTML 模块** 拖到某个**格子**里（或直接点组件，会放进当前选中的格子）。
4. **改属性**：点一下画布上的组件，右侧面板出现它的设置项，按需修改（见第 6 节）。
5. **保存 / 导出**：
   - 想留在本机下次接着改：点「模板」组的 **保存模板**（读的时候点 **读取模板**）。
   - 想备份或发给别人：点 **导出文件**（生成 `.json` 文件）；对方点 **导入文件** 就能还原你的模板。

> 顶部左边有 **「● 未保存 / 已保存」** 提示：改了东西没保存会显示“未保存”，关页面前记得保存，否则白做。

## 6. 组件说明（左侧零件库）

左侧分两组：**基础组件**（往表里填内容的）和 **布局组件**（用来排版定位的）。

### 基础组件（内容）

| 组件 | 是什么 | 典型用途 |
|------|--------|----------|
| **文本** | 固定不变的文字，不能填 | 标题、栏目标题、说明文字（如“工作负责人（监护人）”） |
| **输入框** | 可以填写的字段 | 凡是作业时要手写的地方（姓名、编号、内容…） |
| **图片** | 图片占位框 | 盖章区、示意图、签名扫描件等 |
| **HTML 模块** | 自由排版的自定义块 | 特殊版式用，**不懂 HTML 不用管它**；字段用 `{{字段名}}` 或 `<p data-field="字段名">` 标记，填写态自动变可填、权限/采集同输入框 |

### 布局组件（架子）

| 组件 | 是什么 | 典型用途 |
|------|--------|----------|
| **网格** | 一块按行列划分的布局区 | 把一张票分成若干区块，是每个段落的“容器” |
| **表格** | 多行多列的表 | 设备清单、措施列表等行列数据 |

### 右侧属性面板（选中后改设置）

点中不同东西，右边显示不同设置：

- **页面**（默认选中第一页）：纸张大小（A4 / A3）、页边距、行高、是否显示页眉页脚、分页开关。
- **网格**：有几列、边框样式（全框 / 只外框 / 只内线 / 无）、格子间距、行数、格子默认样式。
- **格子**（网格里的某个小格）：是否内容撑满格子、内边距、对齐方式。
- **文本**：显示文字、字体大小、加粗、对齐。
- **输入框**：字段名称、输入方式（普通打字，或选日期等专用输入）、输入区宽度、默认值、是否显示内边框。
- **图片**：图片地址（或数据字段）、填充方式（等比 / 裁剪 / 拉伸）、尺寸。
- **表格**：行数、列数、边框样式。

> 右侧面板顶部显示「组件类型 / 当前选中」，比如选中网格里的某个格子会显示“格子 1-2”（第 1 行第 2 列），方便你确认选对了没。

## 7. 结构树（左侧下半部分）

左侧「结构」下面是一棵树，把整张表从大到小列出来（页面 → 网格 → 格子 → 里面的组件）。

- **点树里的任意一项** = 选中它，右边就能改它的属性（比在画布上找小字方便）。
- **点画布上的组件** = 树里同步高亮同一项，并自动滚动到它；哪怕它所在的层级之前被折叠了，也会自动展开到看得见为止。
- **删除** 按钮：删掉当前选中的组件（页面和格子不能删）。
- **折叠全部 / 展开全部**：表太长时收起或展开整棵树。

## 8. 填写与打印

### 填写
1. 点工具栏 **「预览」** 进入预览态。
2. 在输入框里直接打字填写。
3. 填好后可以：
   - **保存数据 / 读取数据**：存到本机，下次打开接着填。
   - **导出数据 / 导入数据**：存成 `.json` 文件带走或发给别人，下次导入继续填。

### 专用输入方式（点击输入框召唤外部选择器）

部分输入框在制作时被设为「专用输入方式」（比如选日期）。这类输入框**不用你手动打字**：

- 在预览态**点击该输入框**，会自动弹出对应的选择组件（如日期选择器）；
- 选好后票面自动填上结果，照常可以保存 / 导出。

> 表单上不会出现额外的按钮——触发入口就是输入框本身。具体能召唤什么选择器，由表单制作者在右侧「输入方式」里配置；普通文本框则直接打字填写。

### 打印
- 在预览态或设计态点 **「打印」** 即可。
- 打印**自动按纸张分页**（一页放不下会分到下一页），方向由纸张尺寸决定（A4 竖打、A3 横打），不用手动设。
- 打出来的**只有票面本身**：系统菜单、工具栏、页面其他区域都不会跟着打出来。

> 没配置地址的图片，屏幕上显示占位灰框方便你选中编辑，但**打印时不占位置**，不会多出空白。

> 输入框默认带的下划线（表示“这里可填写”）**打印时不显示**，让票面保持干净；只有你在该字段勾选了「显示内部边框」时，逐行实线边框才会打印出来。

## 9. 快捷键（设计时可用）

> 在输入框里打字时，这些快捷键让位给输入，不会触发下面的操作。

| 快捷键 | 作用 |
|--------|------|
| `Ctrl/Cmd + Z` | 撤销 |
| `Ctrl/Cmd + Shift + Z` 或 `Ctrl/Cmd + Y` | 重做 |
| `Ctrl/Cmd + S` | 保存模板（本机） |
| `Ctrl/Cmd + C` | 复制选中的组件 |
| `Ctrl/Cmd + X` | 剪切选中的组件 |
| `Ctrl/Cmd + V` | 粘贴 |
| `Ctrl/Cmd + D` | 原地复制一份选中的组件 |
| `Delete` / `Backspace` | 删除选中的组件（仅设计态） |

## 10. 常见问题

**Q：拖了组件但看不到 / 放不进去？**
先确认选中的是某个**格子**（点一下网格里的空位），再把组件拖进去或点左侧组件按钮。组件必须落在格子里。

**Q：预览里能改结构吗？**
不能。预览态只能填写内容、检查效果；要改结构请点「退出预览」回到设计态。

**Q：导出的文件是什么？**
模板和填写数据都是 `.json` 文件，本质是一个文本备份，可以导入还原，也能发给同事。

**Q：忘记保存关了页面？**
若显示过“未保存”，关闭时浏览器会提醒。平时养成随手点「保存」的习惯最稳妥。

**Q：怎么知道有没有排版问题？**
底部状态栏显示“待处理问题”数量；点右侧面板里的提示可跳到对应位置修正。
